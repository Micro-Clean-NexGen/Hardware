## Hardware
This document describes the hardware architecture and operating principles of our robot's Mobility and Autonomous Navigation subsystem — the first subsystem being developed for the MVP. It covers locomotion, real-time localization, and obstacle detection and avoidance.

The Steam Cleaning, Air Treatment, along with the full Power Management and Electrical Architecture, will be documented later as development on those areas proceeds. This document follows the same format so all subsystem documents remain consistent and easy to compare.

This documentation covers: electrical wiring, power distribution, computing, sensors, motor control, the bill of materials, and safety notes.
